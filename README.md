# taraArduinoLib
Arduino library for ESP based Bluetooth Cash Terminals.
Basic and easy setup.


## Connection:

Coin slot-----------> Allan 1222 -----------> ESP32 </br>

### Basic Setup
```
Coin slot - Allan 1222 
white     - com 
black     - gnd 
red       - 12v 
```

```
Allan 1222 - ESP32 
no         - 23 
com        - gnd 
```
