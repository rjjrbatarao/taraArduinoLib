# taraArduinoLib
Arduino library for ESP based Bluetooth Cash Terminals

## Connection:

Coin slot-----------> Allan 1222 -----------> ESP32 </br>

### Basic Setup
```
Coin slot - Allan 1222 </br>
white     - com </br>
black     - gnd </br>
red       - 12v </br>
```

```
Allan 1222 - ESP32 </br>
no         - 23 </br>
com        - gnd </br>
```
